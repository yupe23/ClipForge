# VidRepurpose

A Next.js 14 SaaS starter for AI-powered video repurposing.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Prisma + PostgreSQL
- Clerk auth
- Stripe payments
- BullMQ + Redis
- Cloudflare R2
- Python worker for ffmpeg + Whisper

## Quick start

1. Install dependencies: `npm install`
2. Configure environment variables in `.env`
3. Run `npx prisma generate`
4. Run `npm run dev`
